# パチモンスリープ

パチモンスリープの「おてつだい」を、指定した時間ぶん乱数で試行するシミュレーションアプリです。
Godot 4.7（GDScript）製で、Web に書き出して遊べます。ゲーム画面は縦長 9:16（720×1280）のまま中央に置き、ブラウザの残りの幅は濃い黒の余白として表示します。

## 遊び方

1. 画面下の「－／＋」で時間を選び、「n時間分すすめる」を押す
2. パチモン（図形）の上にアイコンが出たらタップ。きのみ・食材が足元にぽこぽこ出る
   - メインスキルのストックがあると画面が暗くなり「！」（ストック数ぶん）とスキルの吹き出しが出る
3. 足元のきのみ・食材をタップするか、指（マウス）でなぞると収容箱へ入る（取得内容は画面右の時計の下に一定時間表示）
4. きのみ・食材収容箱（上に白い角丸の名札が出ている）をタップすると、きのみ・食材それぞれの今の収容数と食材ごとの数を表示（きのみ 99999、食材 800 まで。入りきらない分はフィールドに残る）
5. アイコンの出ていないとき、パチモンの上に「…」の吹き出しが出る（設定パネルを開いているあいだは出ない）。タップすると、画面左から設定パネルがせり出す（もう一度タップか「×」で閉じる）
   - 画面の幅が広いとき（フィールド＋パネルが横に並ぶとき）は、パネルを出したままフィールドや画面下の操作ができる
   - 狭いときはパネルがフィールドに重なり、パネルの外をタップしても閉じる
   - おてつだいボーナスといいキャンプチケットは設定パネルにはなく、画面下で決める（下の「チーム全体の設定」）
   - 変えた値は次の「すすめる」から反映される
   - 食材枠2・3の数は、Lv.30・Lv.60 に届くまで入力できない（薄く表示）
   - サブスキルは Lv.10・25・50・70・80 で1つずつ、最大5つまで選べる。レベルを下げて選べる数が減ると一覧の下の項目から外れる（上げても自動では付かない）
6. 画面の右上隅にはアナログ時計がある。朝4:00から始まり、「すすめる」で進んだ時間ぶん短針・長針が回る（リセットで4:00に戻る）。時刻に合わせてフィールドの背景が昼（7〜16時）・夕方（16〜18時、オレンジがかる）・夜（18〜翌7時、暗くなる）に変わる（見た目だけで、おてつだいの計算には影響しない）
7. 画面左上にはリセットからの累計（おてつだい・きのみ・食材・スキル（うち天井）・いつのまに育成の回数）が出る。きのみ・食材・スキルの回数には、期待値をかっこ書きで添える（例：食材回数 10回（7.3））。おてつだい回数の右に「（）内は期待値」と出す。期待値は「すすめる」1回ごとに、そのあいだのおてつだい回数（いつのまに育成の回を除く）から二項分布で求めて足していく。食材は 回数×食材確率、きのみは 回数×(1−食材確率)。スキルは天井込みで、進め始めたときの不発カウントとストック数から、その2つの状態にいる確率をおてつだい1回ごとに追いかけて求める（ストックが上限の状態では抽選しない）。食材回数とスキル回数の期待値の横の ⓘ を押すと、その回数の確率分布の棒グラフ（横軸が回数、縦軸が確率質量。現時点の回数の棒は紫、期待値は破線。下位15%と上位15%を除いた期待値まわり70%の範囲は薄い青の背景。下位5%は濃い赤、その先15%までは薄い赤、上位15%〜5%は薄い緑、上位5%は濃い緑の背景）が出て、現時点での回数が「下位○%（n回以下になる確率）」か「上位○%（n回以上になる確率）」のどちらか小さいほうで示される。説明文には各背景の色見本（下位5%・下位5〜15%・期待値まわり70%・上位5〜15%・上位5%）も出す。薄い青の範囲の端は、回数 x の確率が x−0.5〜x+0.5 に均等に広がっているとみなして小数で求めるので、棒の途中に来る。分布は期待値と同じく「すすめる」ごとに、食材は二項分布、スキルは天井込みの状態の追跡から求めてたたみ込む。フィールド右の机（ノートが載っている）をタップすると、画面右からおてつだい1回ごとの記録（回・何日目か・時刻（時計と同じ。朝4:00 で日付が変わる）・獲得したもののアイコンと数・スキル発動の「！」）の表がせり出す（机をもう一度タップか「×」で閉じる）。天井で発動した回は赤い「！」に「天井」と添える。パチモンをタップした時点には水色の「タップ」行が入り、フィールドへ出した数と使ったスキルのストック（パチモンの頭上と同じ「！」「！！」）が分かる。タップ前のおてつだいの行のスキルはまだストックにあるだけなので、薄い「！」に「予約」（天井なら「天井予約」）と添える（回の番号はおてつだいだけで数える）
   - 設定パネルと同じく、画面の幅が広いときはフィールドの横に並べて出したまま操作でき、「すすめる」やリセットに合わせて更新される。狭いときはフィールドに重なり、パネルの外をタップしても閉じる

8. 画面下のいちばん上の行は、チーム全体の設定。パチモンと妖精の全員に同じ値が入り、へんしんリストの変身では変わらない（記憶もしない）
   - 「おてつだいボーナス」はチームにいるおてつだいボーナスの数（0〜5個）。1つにつきおてつだい時間 −5%（サブスキルと合わせて最大 −35%）
   - 「いいキャンプチケット」にチェックを入れると、最大所持数とおてつだいスピードが 1.2倍
   - 変えた値は次の「すすめる」から反映される

9. げんきが「100から減少」のとき、パチモンの左右に妖精が2つ出る（げんき回復役。「81以上で固定」のときは出ない）。最初はどちらも休んでいて、地上で止まっている（薄く表示）。休んでいる妖精はいつも「…」を出す。タップすると妖精の設定欄が出る（もう一度タップか「×」、フィールドのほかの場所のタップで閉じる）
   - 「回復する」にチェックを入れると、パチモンの肩あたりの高さに浮かんで漂い、その時点からパチモンと同じようにおてつだいをする（外すと休み、持っている分とスキルのストックは捨てる。休んでいるあいだはげんきも減らない）
   - 「回復量」はメインスキル1回でげんきを増やす量。マイナスにすると減らす
   - 「効果の対象」はスキルが効く相手（パチモン・妖精1・妖精2。初期はすべてチェック）。休んでいる妖精には効かない
   - 「変身」はへんしんリスト（設定パネルと同じ見た目のプルダウン）。項目を選んだ時点でその設定が妖精に入る（妖精の側には保存機能はない）。初期は「回復役」
   - 回復している妖精の頭上にアイコンが出たらタップできる。きのみ・食材は落とさず、そのとき持っていた分は消える（収容箱には入らない）。スキルのストックがあればカットインが出て、効果の対象のげんきが 回復量×ストック数 だけ増減する。ストックがなければ不発で、角丸の「＞＜」を出し、右肩を落とすように傾きながら沈んで（沈む深さは 不発回数÷スキル連続不発上限 の割合で、上限に届くとパチモンの手のあたりの高さまで）、しばらくして元の高さに戻る
   - 妖精のげんきも左上に出る（「100から減少」のとき）

10. ベッドかその上の「ねむる」の札（角丸四角形）をタップすると睡眠の設定欄が出る（もう一度タップか「×」、フィールドのほかの場所のタップで閉じる）
   - 睡眠時間は30分刻み（30分〜24時間、初期は8時間30分）。眠るもの（パチモンと「回復する」がONの妖精）ごとに、起きたときのげんき回復量が出る
   - 「ねむる」を押すと睡眠時間ぶん時間が進む。眠っているあいだもおてつだいとげんきの減少は通常どおり進み、起きた時点でげんきが回復する。休んでいる妖精は眠らない（時間だけ進み、げんきは減りも回復もしない）
11. 島の右下の風船（「おみくじ」の吹き出し）をタップするとおみくじの設定欄が出る（もう一度タップか「×」、フィールドのほかの場所のタップで閉じる）
   - 「有効にする」（初期は無効）、あたりの確率（初期10%）、連続はずれの上限（初期10回、0〜99回）
   - 有効のあいだ、パチモンのメインスキル1回（ストック1つ）ごとにあたり／はずれを引く。はずれが上限まで続いたら次は必ずあたり。あたりで連続はずれは0に戻る
   - 無効のとき風船は地面に転がり、有効のときは糸を張って浮く。風船には連続はずれの回数を書き、上限に対する割合で膨らむ（上限でもとの5倍、数字も一緒に大きくなる）
   - あたりのときは、カットインの「！」のあとで風船が割れて花火が上がり、そのあとに吹き出しが出る。花火は割合に応じて3段階（3分の1、3分の2で切り替え）、上限であたったときは画面が見えなくなるくらいの大あたり演出（回る後光・光の波・金貨の雨・画面の揺れ）。文字は出さない。暗転が明けると新しい風船が出る

回収しなくても次の時間へ進めます。フィールドに残したきのみ・食材も所持数に数えます。

## ロジック

基礎資料の「おてつだい」「おてつだい計算モデル」に従っています（`scripts/sim.gd`）。

- おてつだい時間 = 基準時間 × レベル補正（1−0.002×(レベル−1)）× せいかく補正 × サブスキル補正 × おやすみリボン補正 を小数点以下切り捨て
  - せいかく：おてつだいスピード上昇で時間 0.9倍、下降で 1.075倍
  - サブスキル：おてつだいスピードM −14%・S −7%、チームのおてつだいボーナス1つにつき −5%。合わせて最大 −35%
  - いいキャンプチケット：おてつだい時間 ÷1.2、最大所持数 ×1.2（切り上げ）
  - おやすみリボン：あと1回進化できる 500時間〜 0.95／2000時間〜 0.88、あと2回 500時間〜 0.89／2000時間〜 0.75（最終進化形は補正なし）
- おてつだい間隔 = おてつだい時間 × げんき補正（そのおてつだいを始めた時点のげんき。81以上 0.45／61以上 0.52／41以上 0.58／1以上 0.66／0 は 1.0）
- 1回ごとに確率 p で食材（解放済みの枠から等確率。枠2は Lv.30、枠3は Lv.60 で解放）、1−p できのみ
  - p = 食材確率 × せいかく（1.2／0.8）×（1＋食材確率アップ M 0.36・S 0.18）
  - きのみの数S で1回のきのみ +1個
- 独立に確率 q でメインスキル発動（q = スキル発生確率 × せいかく（1.2／0.8）×（1＋スキル確率アップ M 0.36・S 0.18））
  - ストックが上限のあいだは抽選しない。抽選に 天井 回続けて外れると、次のおてつだいで必ず発動する（天井20なら20回不発のあと21回目）。ストックがあるときにパチモンをタップすると、ストックと一緒に不発カウントも0に戻る（ストックがないタップでは戻らない）
  - 天井で出たスキルは画面下に赤い「天井」の印が付き、スキルの吹き出しにも「天井で発動」と出る。画面下には「スキル天井まで あと○回」も出す
- 最大所持数 = 設定値 ＋ 最大所持数アップ（L 18・M 12・S 6）＋ おやすみリボン（200時間 +1／500時間 +3／1000時間 +6／2000時間 +8）
- 所持数が最大所持数に達していると「いつのまに育成」（きのみはカビゴンへ自動で渡り、食材もスキルも出ない）
- げんきは「81以上で固定」か「100から10分ごとに1減少」を選べる。「100から減少」では妖精のメインスキルで増減する（0〜150。10分ごとに減る区切りは変わらない）。「81以上で固定」では増減しない
- 睡眠の回復量 = 睡眠時間 ÷ 8時間30分 × 100（100まで）× せいかく（げんき回復 上昇1.2倍／下降0.88倍）を四捨五入（下降なら最大88）。回復後のげんきも100まで（もともと100以上なら変わらない）。「81以上で固定」では変わらない
- 妖精もパチモンと同じ計算でおてつだいをする（自分のパラメータ・げんき・所持数・スキル天井を持つ）
- 途中まで進んだおてつだいは次の「すすめる」に持ち越す

せいかくの「げんき回復」は、妖精のメインスキルでげんきが増えるとき、受け取る側（パチモン・妖精それぞれ）のせいかくで 上昇 1.2倍／下降 0.88倍 にして小数点以下を切り捨てます。回復量がマイナス（げんきが減る）ときは掛けません。

パチモンの初期パラメータ（`scripts/params.gd`、設定パネル `scripts/settings_panel.gd` で変更可）：ベアビヲ9、レベル 60、基準おてつだい時間 2200秒（設定パネルの上下ボタンは50秒ずつ、手入力は1秒単位、おてつだい時間 1940秒）、食材確率 15.1%、スキル発生確率 3.9%、スキル連続不発上限 65回、スキルストック 2回、最大所持数 22、きのみ 1個／回、食材枠1 ×1、食材枠2 ×2、食材枠3 ×4、進化できる回数 0、睡眠時間 0時間、サブスキル・せいかくなし。 名前は全角6文字・半角12文字まで（全角2・半角1で数えて12まで）。
テストは基礎資料の計算例（レベル補正なし・最大所持数 25・食材2枠）のパラメータを組んで照合しています。

## 開発

```sh
godot --headless --import
godot --headless -s res://tests/test_sim.gd            # ロジックのテスト（計算例その1・その2と照合）
godot --headless --export-release "Web" build/web/index.html
```

GitHub Actions（`.github/workflows/web.yml`）がテストと Web 書き出しを行い、main では GitHub Pages に公開します
（リポジトリの Settings → Pages で Source を「GitHub Actions」にしておく必要があります）。
Web 書き出しはスレッドなし（`variant/thread_support=false`）なので、特別なヘッダーなしで GitHub Pages 上で動きます。
